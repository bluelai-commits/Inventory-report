# 持股盤後分析 — 執行準則

適用於「台股持股盤後分析」這個持續性任務。核心目標是**每天掌握資金方向**（三大法人動向、產業資金流向、個股籌碼異常），技術價位類資訊則不用天天重查，藉此在不犧牲資金流向判斷準確度的前提下降低token消耗。

## 一、資料分兩類，處理方式不同

### 類別A：資金方向相關（每天都要準確、不省略）
- 大盤三大法人合計買賣超金額與方向
- 外資/投信/自營商買賣超排行、新面孔
- 持股清單中每一檔的**當日漲跌幅**與**是否有法人大量買賣超**（籌碼異常）
- 產業族群當日資金流向與消息面（例如：外資今天是流入還是流出某族群、有無族群輪動跡象）
- 處置股/注意股、大股東申報轉讓、MSCI等籌碼面事件

➜ 這類資料**照舊，不減少搜尋次數**，子代理該查幾次就查幾次，務求數字正確，這是任務的核心價值。

### 類別B：技術價位相關（可降頻，非每日重查）
- 個股支撐價、壓力價（均線/前波高低點）
- 法人目標價（券商報告）
- 技術型態判斷（強勢創高/橫盤/突破平台等）

➜ 這類資料**每週完整查一次即可**（例如每週一或每次使用者要求時），其餘交易日的報告直接沿用最近一次查到的數字，並註明「支撐/壓力/目標價查詢日期：X月X日」，不用每天重新搜尋。若使用者當天特別問到某檔，才單獨即時查證。

## 二、子代理研究輸出格式（僅適用於類別A的籌碼/消息研究）

回報格式一律採緊湊條列，不寫長篇敘述，不逐檔附完整來源URL清單（來源列在文末共用清單即可）：

```
[代號] [名稱]｜現價/漲跌幅｜當日法人動向(有無大額買賣超)｜當日消息面(一句話)
```

## 三、子代理分批方式

- 34檔持股依「類別A每日查證」與「類別B每週查證」分開排程：
  - 每日：可用2-3個較大批次處理現價/漲跌/籌碼/消息（資料量較小，查詢速度快）
  - 每週：用2-3個批次做完整的支撐/壓力/目標價研究（資料量較大，但一週只做一次）

## 四、最終報告

- 第一、二、四部分（大盤、三大法人、籌碼注意事項）**維持完整深度**，不精簡。
- 第三部分「產業解析」聚焦當日資金流向與消息面，每族群2-3句話（含資金流入/流出方向），不用technical細節。
- 第五部分表格：現價/漲跌/籌碼欄位每天更新；支撐/壓力/目標價欄位沿用最近一次週查結果並註明查詢日期，非本週新查則不重複搜尋。
- 免責聲明統一附註一次，不用每列重複。
