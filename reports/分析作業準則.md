# 持股盤後分析 — 執行準則

適用於「台股持股盤後分析」這個持續性任務。

## 目前模式：資金流向導向 + 範圍限定版個股分析（2026-10-05起生效）

主軸仍是**完全聚焦在資金流向**——大盤三大法人買賣超、外資/投信買賣超排行榜、以及「持股所屬產業族群」當天資金流入/流出的方向與原因。持股清單（holdings.md）用途是**幫報告挑出與你相關的族群/個股來講資金故事**。

**2026-10-05 更新**：使用者反饋要恢復個股層級的股價/支撐壓力/法人目標價分析，但**範圍限定**：只對「當天上三大法人買賣超排行榜，或有重大異動（登上排行榜、量能/價格明顯異常）」的持股做個股層級深入分析，不逐檔全面鋪開（避免回到舊模式查證量過大、近半數查無數字的問題）。詳見下方「個股層級分析」一節。

## 報告結構（六大部分）

1. **大盤資金總覽**：加權指數收盤/漲跌/成交量、三大法人合計買賣超方向與規模、當日資金面定調（例如：系統性風險趨避 vs. 個別族群輪動）。**加入國際股市連動**：前一夜美股四大指數、費城半導體指數(SOX)、台積電ADR表現，作為當天台股開盤前的背景（這類資料時效為「隔夜」，相對可信）。
2. **近期事件**（2026-10-15新增，固定章節，詳見下方「近期事件」一節）：大盤與總體事件、法說會日期與重點、產業消息、個股公告、接下來的事件日曆。
3. **三大法人買賣超排行榜**：外資買超/賣超前10、投信買超/賣超前10、自營商動向、新面孔（排行榜上罕見出現或大幅躍升的標的）。**若持股清單中的股票出現在排行榜上，要點名標註**。
4. **持股族群資金流向與漲跌原因**：依 holdings.md 動態分類（記憶體、PCB/載板、半導體代工、散熱…等），逐族群講「今天資金往哪裡去、為什麼」。原因可直接引用第二部分「近期事件」查到的產業消息/個股公告，不用重複搜尋；若該族群有第二部分未涵蓋到的新角度，再補充：
   - **產業鏈關聯**：上下游連動（例如記憶體漲價牽動模組廠、PCB缺貨牽動上游材料廠），一次搜尋族群關鍵字通常能帶出關聯個股。
   族群層級敘述仍**不寫個股現價、不寫支撐壓力、不寫法人目標價**，只講資金方向與原因；若某檔當天有重大異動（例如漲跌停、遭大額買賣超、登上排行榜），在這裡點名並說明「為什麼」，個股的現價/支撐壓力/目標價移到新增的「個股層級分析」部分處理（見下）。
5. **大戶籌碼與注意事項**：處置股/注意股、大股東申報轉讓、庫藏股、MSCI/富時指數調整等籌碼面事件，並標註是否與持股相關。
6. **明日觀察重點**：風險提示、與持股族群相關的後續觀察點（法說會/財報行事曆等具體事件日期已移到第二部分「近期事件」的事件日曆，這裡只做策略性提醒，不重複列清單）。

**免責聲明**（文末統一附一次）：以上內容整理自公開網路資訊，僅供資金流向參考，不構成投資建議。

## 近期事件（2026-10-15新增，每次分析固定納入）

使用者反饋：過去的分析沒有系統性納入「近期事件」，導致看技術面/資金面時缺乏消息面背景（例如看不出某檔爆量是因為法說會或營收公告）。**自2026-10-15起，每次台股持股盤後分析都固定包含這一塊**，放在第二部分，內容涵蓋：

1. **大盤與總體事件**：Fed利率決策、CPI/PPI公布、重大地緣政治/政策事件（如關稅、出口管制、供應鏈查核）、國際股市連動的背景事件（不只是漲跌數字，要講「為什麼」）。
2. **法說會日期**：持股清單中，近期已召開或即將召開法說會的個股，列出日期與重點內容摘要（已召開的列重點，未召開的列預告日期）。
3. **產業消息**：持股所屬產業族群的供需、價格、訂單動態（例如 ABF載板缺貨到幾年、Low DK材料供不應求、AI伺服器資本支出等），對應到第四部分「持股族群資金流向」的原因佐證。
4. **個股公告**：持股清單中有公告月營收（年增/月增%）、重大訊息（處置股、庫藏股、私募、合併收購、董事會決議等）的個股，逐一列出。
5. **接下來的事件日曆**：未來1-2週已知的排程事件，依時間排序列出（例如：法說會、財報公布、Fed會議、CPI公布日、除權息等），讓使用者知道近期要留意什麼時間點。

**查證方式與可信度**：套用前述「資料可信度分級與驗證技巧」——法說會內容、月營收數字屬於中可信度（時效通常幾天內，日期較不易錯置），但仍要核對文章提及的其他細節（例如營收數字、EPS）是否互相一致，避免誤用舊年度同月份的舊新聞（例如查2026年10月，卻混入2025年10月或2024年10月的法說會/營收舊聞）。查無資料的項目誠實標記「查無近期公告」，不要用更早期的舊資料充數。

**呈現方式**：第二部分用表格或條列呈現，依「大盤總體 / 法說會 / 產業消息 / 個股公告 / 事件日曆」五個子類分組；若某子類當天查無新資料，保留標題並註明「本次查無新增事件」，不要省略整個子類（維持報告結構的一致性，方便長期比對）。

## 資料可信度分級與驗證技巧（2026-10-05新增，務必遵守）

實測發現：搜尋引擎對「三大法人買賣超OO億元」這類當日即時金額的查詢，非常容易混入**其他年份、其他月份但同樣是「X日」的舊新聞**（例如查10月5日，卻混入2024年3月5日、2025年1月5日、2026年8月5日的資料），而且這些舊資料偽裝得像真的（數字具體、敘述完整），光看內容難以分辨。因此：

### 可信度分級
- **高可信度**（可直接採用）：當天已用其他管道確認過的具體事實作為「錨點」（例如確認過的加權指數收盤點數、個股收盤價），之後查到的其他資料只要能與錨點交叉對應（例如新聞同時提到「台積電收2575元」且與錨點一致），可信度較高。
- **中可信度**：產業基本面（月營收、法說會）、消息面事件，時效通常是幾天內，日期標示相對不會錯置。
- **低可信度／需驗證**：當日三大法人精確買賣超金額、當日個股精確現價與漲跌幅——這類數字最容易被錯誤日期的舊新聞污染，**查到後務必先核對文中其他可驗證的細節（指數點位、個股價位、具體事件）是否與當天已知的錨點一致，不一致就捨棄，絕不能照單全收**。

### 驗證步驟
1. 先透過1-2次搜尋確認當天「錨點事實」（加權指數收盤點數、最大權值股台積電的收盤價與漲跌）。
2. 之後每查到一筆「三大法人／投信／自營商」的金額數字，檢查該篇文章是否也提到與錨點一致的指數點位或個股價位；若文章內容與錨點明顯不符（例如指數點位差了好幾千點、年份對不上），直接捨棄，不採用、不混用。
3. 若多次嘗試後仍找不到與錨點一致的投信/自營商數字，**誠實回報「查無可靠數字」**，並說明已嘗試的驗證方式，不要為了填滿報告欄位而使用未經驗證的數字。

### 已知的工具限制
- WebFetch 對 twse.com.tw（證交所官網）、cnyes.com（鉅亨網）、wantgoo.com（玩股網）等主要台股資訊站**全部被環境的網路出口代理（egress proxy）封鎖**，無法直接抓取官方頁面核對，只能依賴 WebSearch 的摘要結果，务必搭配上述驗證技巧使用。
- 当日精確的個股現價/三大法人精確金額，使用者的看盤軟體/證券App永遠比我查到的更準，遇到驗證不過的數字，直接請使用者自行確認，不要硬湊。

## 延伸判斷指標（2026-10-05新增，視情況使用，非每日強制）

除了三大法人現貨買賣超，以下指標能幫助更全面判斷資金方向與市場氣氛，查得到就加入報告，查不到就略過，不用為了湊齊而硬查：

- **外資台指期貨淨部位、選擇權Put/Call比**：反映法人對大盤方向的期貨/選擇權籌碼看法，現貨買賣超搭配期貨淨部位一起看，比單看現貨更能判斷法人是真偏多還是避險操作。
- **新台幣兌美元匯率**：外資匯入買股常伴隨新台幣升值，匯率變化可作為外資資金流向的輔助判斷，尤其現貨數字查不到時可作為替代訊號。
- **台積電ADR溢/折價率**：美股收盤時間早於台股開盤，ADR相對台股的溢價或折價，是判斷隔夜台股開盤前氣氛的領先指標，可併入第一部分的「國際股市連動」小節。
- **類股指數強弱 vs 大盤**：例如電子類指數、半導體類指數漲跌是否跟大盤同步，有助判斷是全面性行情還是資金集中在少數族群（族群輪動 vs 齊漲齊跌）。
- **融資融券餘額變化**：融資餘額驟減常是籌碼鬆動/恐慌性斷頭訊號；融券(放空)餘額增加可看空方力道增溫，可作為籌碼面風險提示的輔助依據。
- **千張大戶持股比例變化**：集保戶股權分散表的大戶占比升降，可輔助判斷個股籌碼是集中(大戶惜售)還是鬆動(大戶出貨)，屬於第四部分「大戶籌碼」的延伸。
- **成交值集中度**：某族群當日成交值占大盤比重，可具體化「資金集中在哪」的程度（例如「PCB族群今日成交值占大盤15%」比單純說「資金流入PCB」更有說服力），查得到才用，查不到不用硬湊。

**重要提醒**：以上延伸指標同樣適用前述「資料可信度分級與驗證技巧」，尤其期貨未平倉、融資融券餘額這類數字，一樣容易被日期錯置的舊新聞污染，查到後要跟錨點事實交叉核對。

## 個股層級分析（2026-10-05 重新啟用，範圍限定版）

**觸發條件**（只對符合以下任一條件的持股做，不是全部31檔都做）：
- 當天登上外資/投信/自營商買賣超排行榜（第二部分已查過）
- 當天有明顯異動：漲跌停、量能爆增、法人買賣超金額特別大
- 搜尋族群新聞時該檔被特別提及重大事件（例如法說會、處置股公告）

**三項分析資訊的資料來源與可信度分工**：

1. **現價/OHLC（開高低收）**：優先用官方 API 直接查，不透過搜尋引擎，不受「舊新聞日期錯置」風險影響：
   - 上市：`https://www.twse.com.tw/exchangeReport/STOCK_DAY?response=json&date=YYYYMM01&stockNo=代號`
   - 上櫃：`https://www.tpex.org.tw/www/zh-tw/afterTrading/tradingStock?code=代號&date=YYYY/MM/01&response=json`
   - 可直接呼叫上述 API（或使用已寫好的 `stock_price_analysis.py` 工具腳本），取得精確數字，**不需要再用 WebSearch 查個股現價**。

2. **支撐/壓力**：**兩種來源並用，互相比對**：
   - **自算版**（主要、可靠）：用上述官方歷史收盤資料，計算近N個交易日區間高低點、MA5/MA20/MA60，作為支撐壓力的「錨點版本」。
   - **分析師搜尋版**（輔助、需驗證）：搜尋網路分析師畫的支撐壓力線，**套用前述「資料可信度分級與驗證技巧」**跟錨點版本交叉比對；若分析師說法與自算版差距過大或文章內容與當天錨點事實（指數點位、該股收盤價）不符，直接捨棄不採用，並在報告中註明「自算版 vs 搜尋版有分歧，以自算版為準」。

3. **法人目標價**：沒有官方 API，**仍只能靠搜尋**，是三項中唯一無法完全避開舊資料污染風險的部分。查到後務必核對文章提及的該股現價/財報數字是否與當天錨點一致，不一致就捨棄；多次查無可靠數字時，誠實回報「查無可靠目標價」，不要用舊目標價充數。

**呈現方式**：在第三部分「持股族群資金流向」對應族群段落下方，針對觸發條件命中的個股加一小段「個股層級分析」，列出：現價(含漲跌)、近期支撐/壓力(自算，若有搜尋到分析師版本一併列出並註明比對結果)、法人目標價(若查無則註明查無)。未觸發的持股維持原本只講族群資金流向，不逐檔列這些資訊。

## 執行方式

- 大盤、近期事件、三大法人排行榜（第一、二、三部分）：我自己直接用WebSearch查證，通常8-15次搜尋即可涵蓋（比舊版多抓「近期事件」的3-5次：大盤總體事件1-2次、法說會/個股公告2-3次、產業消息視族群數量1-2次），不用開子代理。
  - 法說會/個股公告搜尋可以跟第四部分「持股族群資金流向」合併查，一次搜尋「[族群關鍵字] 法說會 營收」通常能同時帶出族群消息與個股公告，不用分開查兩次。
- 持股族群資金流向（第四部分）：**不用對34檔個股逐一查價**。做法改成：
  1. 查當日外資/投信買賣超排行榜（已在第三部分查過），比對榜單上出現的代號是否落在持股清單的34檔中。
  2. 針對持股所屬的產業族群（例如PCB/載板、記憶體），搜尋「[族群關鍵字] 今日 資金流向/大漲/大跌 原因」「[族群關鍵字] 法說會 營收」這類族群層級的搜尋，一次搜尋通常能涵蓋族群內多檔的資金面+消息面，不用每檔分開查。
  3. 只有當某檔持股當天有重大異動（登上買賣超排行榜、或搜尋族群消息時發現該檔被特別提及）時，才需要再查1次該檔的具體原因（不查價格，只查「為什麼」）。
  4. 這樣通常加計第二部分後約15-25次搜尋即可涵蓋全部34檔所屬的族群＋近期事件，不需要像過去分3-5個批次逐檔查價，子代理可視搜尋量決定是否需要開（若我自己查詢即可涵蓋，不必開子代理）。
- 籌碼注意事項與明日觀察（第五、六部分）：延續原本做法，直接搜尋處置股/注意股等，法說會/財報行事曆已移到第二部分「近期事件」的事件日曆，這裡不重複搜尋。
